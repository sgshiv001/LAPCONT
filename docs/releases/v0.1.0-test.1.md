# LapCont 0.1.0 — Test build 1

Android app, Windows service/companion and optional self-hosted relay. This is a **test prerelease**, with full release acceptance still in progress.

## Downloads

- **LapCont-UI.apk**: optimized Android app, approximately 8.5 MiB. Signed with the existing public QA/debug identity. Install over the matching test app to preserve pairing; production distribution requires a release key.
- **LapCont-Windows-UI-v0.1.0.zip**: Windows service, updated companion, setup scripts and license notices. Requires x64 .NET 8 Desktop Runtime and ASP.NET Core Runtime.
- **LapCont-relay-linux-x64-v0.1.0.zip** and **LapCont-relay-windows-x64-v0.1.0.zip**: optional relay builds for operator-managed deployment. Trusted TLS and private, separately provisioned role credentials are required.
- **SHA256SUMS.txt**: checksums for these four packages.

For an existing Windows installation, quit the old LapCont tray companion and open **Open LapCont.cmd** from the extracted new package. The fresh installer rejects an already installed service. See the repository README for complete setup and pairing steps.

## Recorded validation

App tests were recorded on **6 October 2026**, before this publication:

- 35 Windows regressions and 14 Windows UI component checks passed.
- 8 Android unit checks passed. Six UI tests passed on each of three emulator profiles.
- The exact optimized APK passed launch, pairing-screen Back and quick Back checks on API 29 / 4 KiB and API 37 / 16 KiB emulators.
- Earlier physical builds passed selected pairing, live media, recovery and talk-back checks. The owner confirmed hearing their voice through the laptop speaker.

The Windows archive's documentation was updated for publication and private report addresses were removed. Its 59 executable/library/runtime entries remain byte-for-byte identical to the previous tested UI archive. The Android and relay packages are unchanged.
